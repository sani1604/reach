# Shopify App Store listing assets

Official screenshot size: **1600 × 900 px (16:9)**  
Format: JPEG or PNG · Include 3–6 desktop screenshots  
App icon: **1200 × 1200 px** square  
Source: [Shopify App Store best practices](https://shopify.dev/docs/apps/launch/shopify-app-store/best-practices)

## App icon

| File | Spec |
|------|------|
| `shopify/app-icon-1200.png` | **Preferred** — 1200×1200 PNG |
| `shopify/app-icon-1200.jpg` | JPEG fallback |

- Full-bleed square (Shopify rounds corners automatically)
- Mark: emerald “R” signal + **Reach** wordmark on deep green
- Keep ~10% safe margin from edges (already applied)

Upload under **Partner Dashboard → App listing → App icon**.
